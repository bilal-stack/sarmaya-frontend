# **App Name**: Galsi Prototype

## Core Features:

- Login: User authentication using email and password.
- Signup: User registration with full name, email, and password.
- Input Validation: Real-time validation of email and password format during login and signup.
- Session Management: Manage user sessions to maintain login state.

## Style Guidelines:

- Primary color: Dark charcoal (#333333) for a sophisticated feel.
- Background color: Deep gray (#121212) for a modern dark theme.
- Accent color: Electric purple (#BE95C4) for highlighting interactive elements.
- Font pairing: 'Roboto' (sans-serif) for headlines and 'Open Sans' (sans-serif) for body text. 'Roboto' offers a bold, modern feel for headers, while 'Open Sans' provides excellent readability for the main content.
- Clean, spacious layouts with sharp corners and subtle shadows to create depth.
- Use simple, filled icons for navigation and input fields, with a glowing effect on active states.
- Subtle, smooth transitions and animations to enhance user experience in the dark theme.
